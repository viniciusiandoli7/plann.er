<h1 align="center"> Plann.er ✈️ </h1>

Plann.er é um planejador de viagens desenvolvido durante o evento **NLW Journey** da *Rocketseat*. Com ele, você pode organizar sua rotina de viagem, criando e gerenciando atividades de forma simples e intuitiva.

## 📚 Funcionalidades

- **Execução no VSCode** ✨  
  Ao rodar o código, a página será aberta automaticamente no navegador, exibindo a interface do planejador.

- **Cadastro de Rotina** 📝  
  Assim que o site carregar, você pode começar a planejar seu dia clicando e adicionando atividades à sua agenda de viagem.

- **Data e Hora** ⏰  
  Cada atividade criada precisa ser associada a uma data e horário específicos.

- **Status das Atividades** ✅  
  Para facilitar o controle, há um *checkbox* que permite marcar atividades já realizadas.

## 🖥️ Tecnologias Utilizadas

- **HTML** → Estruturação da página  
- **CSS** → Estilização da interface  
- **JavaScript** → Lógica e interatividade  

## 🔨 Requisitos

Para executar o projeto, é necessário ter instalado:

- [VSCode](https://code.visualstudio.com/download)

## 🕹️ Como Executar

Siga os passos abaixo para rodar o Plann.er:

1. Faça o download do repositório do projeto.  
2. Abra a pasta do projeto no VSCode.  
3. Execute o arquivo principal para iniciar o planejador.
